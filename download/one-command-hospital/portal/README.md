# Portal — program website (Next.js 16)

The stakeholder-facing story of the One-Command Hospital: hero, how-it-works
lifecycle, the 10-repo combination, the six improvements, proof (eval + kill
criteria), compliance framework with open items, deployment, roadmap, risks.

Warm-care design system (cream/pine/terracotta), ambient blobs, animated ECG
trace, scroll reveals, animated counters, `prefers-reduced-motion` respected.

## Run

```bash
cd portal
bun install && bun run dev     # or: npm install && npm run dev
```

The portal is presentation-only: every number it shows traces to a repo
artifact (eval/report.md, docs/architecture.md, eval/qa_seed.yaml,
docker-compose.yml). Built as "a Willow Lab research build".
